# fixtures/egfr

The benchmark target: the **EGFR kinase domain** and a 4-anilinoquinazoline
ligand series. Frozen by [ADR-0007](../../adr/0007-benchmark-target.md).
Generated by `../scripts/make_egfr_receptor.py` and `../scripts/make_ligands.py`;
do not edit these files by hand.

## Receptor and reference crystal

| File | Size | Content |
|---|---|---|
| `receptor.cif` | 160 KB | PDB **4WKQ** chain A, polymer only: 296 residues (Ala694–Gln1020, numbering not gap-free), 2338 atom sites |
| `reference.cif` | 162 KB | the same chain plus gefitinib (`IRE`, 31 atoms) in its crystal pose |
| `reference_ligand.sdf` | 2.7 KB | gefitinib alone, 31 atoms / 34 **explicit bonds** (the arena has no bonds) |
| `pocket.toml` | 3.0 KB | the 22 pocket residues, with each one's distance to the ligand |

**Why 4WKQ** ("1.85 angstrom structure of EGFR kinase domain with gefitinib"):
wild-type human EGFR (UniProt P00533, no mutations), one protein chain, 1.85 Å
— the best-resolved wild-type EGFR kinase domain carrying a ligand of the very
chemotype the series is built from. The alternatives were all worse on one
axis: 1M17 (erlotinib) is 2.60 Å, 2ITY (gefitinib) 3.42 Å, and the sub-1.5 Å
entries (8A27, 5UG9, 5HG8) are L858R/T790M/V948R mutants with non-quinazoline
ligands. See ADR-0007 for the full comparison.

Both files are derived, not the deposited file: solvent (121 waters) and the
crystallisation additives (MES, Na⁺) are removed, and the ANISOU records are
dropped — nothing in mold reads them and they double the file size. Everything
else is as deposited, including:

- **alternate locations** (altloc A/B) on two residues, so these files also
  exercise `mold-mol`'s altloc policy;
- **CSX 797** — in this crystal Cys797 is S-oxidised and is deposited as the
  modified residue `CSX`. It is part of the polymer. Any code that assumes the
  20 standard residues will trip over it, which is the point of having it.

Verified to read cleanly with `pdbtbx` 0.12 (`only_atomic_coords`), 0 warnings.

## Pocket and pocket RMSD

`pocket.toml` lists every polymer residue with a heavy atom within **5.0 Å** of
a gefitinib heavy atom: 22 residues, the textbook EGFR ATP site, including
Leu718, Gly719, Val726, Ala743, Lys745, Thr790 (gatekeeper), Gln791, Met793,
CSX797, Leu844, Thr854 and Asp855. Author numbering, which here equals UniProt
P00533 numbering.

Pocket RMSD is computed over those residues' Cα atoms after superposing the
predicted complex on `reference.cif`. `receptor.cif` comes from the same entry,
so 4WKQ-against-4WKQ is zero by construction; for a non-degenerate case use the
cross-reference recorded in `pocket.toml` — `../structures/1M17.cif`, EGFR with
erlotinib at 2.60 Å, same chain and numbering.

## Ligand series

| File | Size | Content |
|---|---|---|
| `ligands.smi` | 31 KB | 401 lines: 395 ligands + 6 deliberately unparsable entries |
| `ligands.bad.txt` | 692 B | the 6 ids that must fail, with the reason for each |
| `ligands.provenance.toml` | 1.4 KB | upstream snapshot checksums, filter counts, versions |

`ligands.smi` is tab-separated with no header, sorted by id, and LF-terminated:

```
SMILES <TAB> id <TAB> pIC50 <TAB> source
COc1cc2ncnc(Nc3cccc(SC)c3)c2cc1OC	EGFR-0001	6.90	pubchem:CID1714
```

- **SMILES** — RDKit canonical SMILES, so the file does not depend on the
  upstream vendor's conventions.
- **id** — `EGFR-0001` … `EGFR-0395`, assigned in ascending PubChem CID order.
  Stable: the file is frozen. The unparsable entries are
  `EGFR-0007-BAD`, `-0063-BAD`, `-0121-BAD`, `-0200-BAD`, `-0288-BAD`,
  `-0377-BAD`, so that a plain sort **interleaves** them with the real ligands
  and a reader that aborts on the first failure fails early rather than at the
  end.
- **pIC50** — 9 − log₁₀(IC50 in nM), from the median of every qualifying
  PubChem IC50 for that compound against EGFR. Range 4.00–11.22, median 7.32.
  `NA` for the unparsable entries.
- **source** — `pubchem:CID<n>`, or `synthetic:bad-smiles`.

**The series.** A compound is in it when it has an EGFR (UniProt P00533) IC50
in PubChem BioAssay with relation `=`, is a 4-anilinoquinazoline substructure
hit, is a single fragment of H/C/N/O/F/S/Cl/Br only, and — the condition that
makes the set congeneric rather than "EGFR inhibitors" — its **Bemis–Murcko
scaffold is exactly 4-anilinoquinazoline**, so the ring system is shared and
only the substituents vary. 1,957 candidates in, 395 out; the full counts are
in `ligands.provenance.toml`. Heavy atoms 17–44, MW 221–616.

**The six bad SMILES**, one per failure mode, each verified to make
`Chem.MolFromSmiles` return `None` with RDKit 2026.09.2: an unclosed ring bond,
an unbalanced parenthesis, a five-bonded nitrogen, an unknown element symbol,
an aromatic five-membered carbocycle that cannot be kekulized, and a compound
name instead of SMILES. They are chemically plausible-looking quinazolines on
purpose. `../scripts/validate_ligands.py` re-checks that exactly these six fail
and all 395 others parse.
