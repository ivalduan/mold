# v0.1 plan

From the *v0.1 Engineering Plan* ([source](https://claude.ai/artifact/2GK7mU3HZBia5LzZGtZzZb)).

## Definition of done: all seven
A structural biologist clones the repo, runs one command, and scrubs 300 co-folded poses at 60 FPS without writing a script.

- [ ] Fresh clone to running demo in under 10 minutes on a Linux workstation with an NVIDIA GPU
- [ ] The graph ingests a receptor and 200–500 ligands, runs poses, gates them, profiles contacts, and displays them
- [ ] Clicking a point in the affinity-vs-confidence plot snaps the viewport to that conformer in under 100 ms
- [ ] 500 poses of a ~3,000-atom complex render at ≥ 60 FPS with sphere, stick and cartoon
- [ ] The graph saves to a readable TOML recipe and replays headless through the CLI with identical outputs
- [ ] The sanity gate agrees with Python PoseBusters on a public test set, within a stated tolerance
- [ ] `cargo test` passes with no GPU and no Python present

## Non-goals for v0.1
Model training or fine-tuning · new science · WebAssembly / browser sharing · multi-user or cloud sync · plugin marketplace or dynamic plugin loading · ray-traced rendering · molecular dynamics · electron density / cryo-EM maps · macOS and Linux app builds (they follow the Windows PoC).

The renderer and the node canvas run in parallel from W1/W2 because they share no code. That parallelism only exists if the crate boundaries hold.

## Performance budget
| Metric | Budget |
|---|---|
| Frame time, 500 poses × ~3,000 atoms | ≤ 16.6 ms |
| Click → re-aimed camera | < 100 ms |
| Gate 500 poses | < 200 ms |
| Load + display 300-ligand result set from cache | < 2 s |

## Tests, in descending order of value
1. Golden-file parser tests on real structures, incl. altlocs and a covalent ligand (`mol`)
2. Gate cross-validation vs. Python PoseBusters, tolerance in the test (`geom`)
3. Property tests on geometry: RMSD invariant under rigid transform; clash counts symmetric (`geom`)
4. Recipe round-trip: graph → TOML → graph is identity; CLI replay gives byte-identical tables (`recipe`)
5. Headless render to PNG + perceptual hash (`render`, GPU CI job)
6. Criterion benchmarks: frame time at 500 poses; gate throughput

CI: Linux, no GPU, no Python. Optional GPU runner later for the render test and real-worker smoke test.

## Instructions for coding agents (from the plan)
1. **Week 0 is a spike; its only deliverable is written decisions.** ADRs for viewport path and GPUI lineage before any application crate gets code.
2. **Build bottom-up**: `mol`, `geom`, `graph` first, with tests, before any UI.
3. **Build the mock worker before the real one.**
4. **The acceptance tests are the spec.** Test first, implementation second.
